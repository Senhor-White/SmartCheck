## 🛡️ Política de Segurança (Offline)

Como este projeto é executado localmente, sua segurança depende diretamente do ambiente em que está sendo utilizado. 🚀

### 🔒 Escopo de Segurança

- **Execução local:** O código não estabelece conexões com servidores externos, contribuindo para a privacidade dos dados do usuário.
